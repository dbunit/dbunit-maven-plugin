A Maven plugin that runs https://dbunit.github.io/dbunit-extension/[dbUnit] database operations as build goals.
It delegates the actual database work to dbunit-core via its Ant task API, making it easy to set up,
tear down, export, and verify database state as part of your Maven build lifecycle.

* link:https://dbunit.github.io/dbunit-maven-plugin/operation-mojo.html[`dbunit:operation`] — Run `INSERT`, `UPDATE`, `DELETE`, `REFRESH` (upsert), `CLEAN_INSERT`, and other composable operations from one or more dataset files.
* link:https://dbunit.github.io/dbunit-maven-plugin/export-mojo.html[`dbunit:export`] — Export table contents, filtered by table or custom query, to a dataset file (XML, flat XML, CSV, XLS, or YAML).
* link:https://dbunit.github.io/dbunit-maven-plugin/compare-mojo.html[`dbunit:compare`] — Compare current database contents against a reference dataset file.
* link:https://dbunit.github.io/dbunit-maven-plugin/export-dtd-mojo.html[`dbunit:export-dtd`] — Export a flat DTD schema ordered by foreign key constraints, for dataset validation and IDE auto-completion.
